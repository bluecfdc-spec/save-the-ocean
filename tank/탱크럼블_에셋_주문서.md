## 0. GPT에게 보내는 안내 (여기서부터 복사)

너는 지금부터 모바일 게임 **TANK RUMBLE**의 아트 디렉터 겸 그림 작가야. 아래 게임 설명과 스타일 규칙을 끝까지 기억하고, 내가 "N번 만들어줘"라고 하면 그 번호의 시트를 규칙대로 한 장 만들어 줘. 완성하면 "N번 완료"라고 말해 줘.

### 게임이 뭔가
- 세로 화면 폰 게임. 화면은 **위 절반 = 상대 진영, 아래 절반 = 내 진영**, 가운데에 전선. 한 전장을 위아래로 나눠 쓴다.
- 내 진영은 **7칸 × 9칸** 땅. 거기에 테트리스 같은 **블록을 끌어다 놓고**, 가로·세로 한 줄을 채우면 줄이 터지며 아이템(연료·정찰기·미사일·보병)을 얻는다.
- 내 땅 위에 **내 탱크 1대**가 있다. 탱크는 빈 칸으로 이동할 수 있다(연료 소모). 탱크는 퍼즐 블록과 확실히 구분돼야 한다.
- 아이템
  - **정찰기**: 상대 진영 위를 5초 날며 상대 탱크·뒷줄 보병을 드러낸다.
  - **미사일**: 내 탱크 세로줄로 곡사(포물선)로 날아가 맨 앞 적 보병, 없으면 그 줄의 상대 탱크를 맞힌다(탱크 체력 3).
  - **보병**: 내 탱크에서 뛰어나와 내 최전방 줄에 선다. 30초마다 전선에서 **교전** — 최전방 보병이 많은 쪽이 전선을 한 줄 민다.
- 보드가 꽉 차면 **붕괴**: 3초 경보 뒤 전선이 2줄 밀리고 블록이 전부 터진다.
- **세력 3개** (오션럼블과 같은 세계관): **서지**(파도·물·청록) / **게일**(폭풍·번개·보라) / **솔라**(태양·빛·금색). 줄 10개를 지우면 **필살기**:
  - 서지 **폭풍우**: 내 땅 전체에 20초 폭풍우. 상대 정찰기는 뜨자마자 번개 맞고 추락.
  - 게일 **낙뢰**: 적 보병 3명에게 벼락.
  - 솔라 **태양 방패**: 탱크에 금빛 보호막(미사일 2발 흡수).
- 승리: 상대 탱크 체력 0, 또는 전선이 상대 탱크를 덮침.

### 스타일 규칙 (모든 그림 공통)
1. **고급 카툰 3D** — 클래시 로얄 / 붐비치 느낌. 선명하고 또렷한 색, 부드러운 라이팅, 두꺼운 실루엣, 폰 작은 화면에서도 한눈에 읽힘. 픽셀아트·도트·납작한 2D·사실적 사진풍 **금지**.
2. **시점**: 위에서 비스듬히 내려다보는 **3/4 탑다운**(약 60도). 유닛·건물·블록 모두 같은 각도. 조명은 **왼쪽 위**에서.
3. **팔레트**: 내 편 = 올리브·카키 + 세력 색 포인트 / 적 = 진한 빨강·검정 / 위험 = 빨강 / 유리 = 초록 / 중립·금 = 금색(#FFD451). 배경은 어둡고 유닛·UI는 밝게.
4. **파일 규칙**:
   - 유닛·효과·UI 조각은 **투명 배경 PNG**. 투명이 안 되면 **순수 초록(#00FF00) 단색 배경**.
   - 시트는 **정확한 격자**(예: 4×4)로, **칸마다 하나씩**, 칸 크기 동일, 그림이 칸 밖으로 나가거나 겹치지 않게, **글자·번호·테두리·그림자 패널 넣지 않기**. 빈 칸은 그냥 비워 둬.
   - 크기는 1024×1024(정사각 시트) 또는 세로 1024×1536(배경).
5. **일관성**: 1번(키 아트)을 만든 뒤에는 모든 시트를 "1번과 같은 스타일·같은 탱크 디자인·같은 색"으로 그려. 탱크·보병·비행기는 매번 같은 디자인이어야 한다.
6. 글씨는 어떤 그림에도 넣지 마(타이틀 로고 제외).

## 2. 받은 뒤 할 일 (홍균 → Claude)
- 그림을 받으면 Claude 대화창에 **번호와 함께** 붙여 넣기: "7번이야".
- 마음에 안 들면 GPT에게 "7번 다시, 탱크 더 크게"처럼 번호+수정만 말하면 됨.
- 순서는 **1번부터 25번까지 차례대로**.
