## 1. 홍균님과 일하는 방식 (꼭 지키기)
- 질문은 **한 번에 하나**, **A/B/C 객관식**으로.
- 작업이 끝날 때마다 **결과 URL**을 답변 끝에 적기. 어디 들어가야 하면 그 URL도.
- 게임 화면은 폰·PC 어느 비율에서도 **빈 띠 없이 꽉 채우기**.
- 디자인·배치 고민은 말로 묻지 말고 **A/B/C 시안 스크린샷**을 보여 주고 고르게.
- **작은 글씨 금지.** 게임 안 안내 문구는 짧고 크게.
- 답변은 짧게. 한 일 위주로, 과정 설명은 줄이기.
- 보안: App Store `.p8` 키, ElevenLabs API 키는 **절대 채팅으로 받지 않음**. GitHub 시크릿(`ASC_KEY_P8`, `ELEVEN_API_KEY`)에만 있음.
- 평일엔 홍균님이 아이패드로만 접속 → 지시만 가능. PC 작업(에셋 뽑기·파일 옮기기)은 주말.

## 3. 소리 (탱크 때와 같은 방식)
- **고르는 도구**: `sfx/pick.html` → https://bluecfdc-spec.github.io/save-the-ocean/sfx/pick.html
  - 목록은 `sfx/manifest.json`. 항목마다 `files`(후보 mp3 경로), `name`, `game`, `num`. `done:true`면 숨김, `hold:true`면 보류(숨김).
  - 홍균님이 후보를 듣고 고르면 끝 화면의 글을 복사해 채팅에 붙여 줌 (예: `스카이_03 = 스카이_03_2_xxx.mp3`, `다시 ← 더 짧게`).
  - 각 항목 설명은 `pick.html`의 `DESC`/`TITLE`에 한국어로 넣기.
- **후보 만드는 순서 (홍균님 요청)**:
  1. **Claude가 직접 만들 수 있는 소리는 직접 합성**(Python/numpy·ffmpeg 등으로 전자음, 띠롱, 슝, 펑, 버튼음 등). 탱크 때 직접 만든 소리가 더 나았음 (보병 투입 소리 `deploy5`, 확인 체크 띠롱 등).
  2. 직접 만들기 어려운 것(실제 폭발 질감, 큰 시네마틱 등)만 ElevenLabs.
     - GitHub Actions `sfx-gen` 워크플로(`.github/workflows/sfx-gen.yml`, `tools/sfx-gen.mjs`)가 시크릿 `ELEVEN_API_KEY`로 `효과음_주문서.md` 표의 프롬프트를 읽어 `sfx/candidates/`에 후보를 만들고 manifest를 갱신함. 실행: `gh workflow run sfx-gen -f game=스카이 -f count=3`.
     - 주문서 표의 프롬프트 칸은 **프롬프트 하나만**(옛것|새것 같이 쓰면 둘 다 읽어 버림).
  - 후보 여러 개를 나란히 들어 보는 간단 테스트 페이지도 가능(예: `tank/soundtest.html`).
- **스카이 소리 목록** (`효과음_주문서.md` 스카이 표, manifest에선 지금 전부 `hold`):
  스카이_01 출격 / 02 탄 스침 / 03 기체 폭발 / 04 저격탄 발사 / 05 탄 소멸(뇌격) / 06 경쟁 기체 격추 / 07 방패 피격 / 08 신기록
  → 시작할 때 `hold`를 풀고 후보를 새로 만들어 고르게 하기.
- 공통 소리(버튼·확인·카운트·승리·패배·필살기 3종)는 이미 탱크에서 골라 둔 것 재사용 가능 (`tank/assets/sfx/`, `tank/sfx.js`의 `SAMPLES` 참고).
- 소리 반영 규칙(탱크에서 정한 것): 경고음은 최소한으로(자주 울리면 시끄러움). 배경음악은 루프 1개 + 승리/패배 음악. 음악 만들 땐 Suno 사용(홍균님이 직접 뽑아 옴).
