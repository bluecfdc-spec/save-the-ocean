# 허브(통합 홈) 인계

> 주소: https://bluecfdc-spec.github.io/save-the-ocean/hub/
> 세 게임을 한 앱으로 묶는 첫 화면. 게임 파일(`/`, `/sky`, `/tank`)은 **하나도 고치지 않았다.**

## 지금 상태 (2026-11-25)

- **전장 홈 화면**: 하늘·바다·땅에서 세 세력이 싸우는 움직이는 화면(`index.html` 안의 그림 코드, `window.WF`). 그림은 `a/`(GPT 제작, 드라이브 'AI 공용 작업실/warfront_assets'가 원본).
- **흐름**: 투입 버튼 → 세력 선택 → 게임(iframe) → 결과 창 → 전장 복귀. 로직은 `hub.js`.
- **게임이 끝난 것을 아는 방법**(게임 파일은 그대로, 같은 주소라 밖에서 지켜봄)
  - 탱크: `TR_RANK.onEnd(점수)`를 감싸서 받음
  - 스페이스: 결과 창 `#ovT`가 GAME OVER, `#ovS`에 버틴 시간이 뜨는 순간
  - 오션: `#overOverlay`가 열리고 `#finalScore`에 점수가 뜨는 순간
  - 게임 쪽에서 이 이름들을 바꾸면 허브가 결과를 못 받는다 → 바꿀 땐 `hub.js`의 `watch()`도 같이.
- **체험·잠금**: 체험 9판(판마다 게임·세력 자유) → **9번째 판만 세력에 기여**하고 그 세력으로 고정 → 이후 이용권이 있으면 매 판 기여, 없으면 하루 3판(기여 없음). 판 수는 이 기기에만 저장(`localStorage dg_hub_v1`).
- **점수**: 기록 → 등급 1~10(`hub.js`의 `GAMES[].th`) → 보급. 약세 세력 보너스 ×1.2 / ×1.5. 전장별 점유율 = (기본 30 + 보급 합) 비율.
- **1등 이름**: 전장·세력별 최고 기록자의 이름이 기함 위에 뜸. 이름은 자동 생성(예: 푸른파도 #4821).
- **서버**: 출시 전 테스트 칸만 씀 — `sky_scores_test` · `ocean_scores_test` · `tank_scores_test`, 익명 로그인. 한 건 = `{name, score(기록), date, flag, faction, uid}`, `flag = 'H' + 달(36진 한 글자) + 보너스 단계(0~2)`. 지금 규칙(`firestore.rules`) 그대로 동작하도록 맞춘 것이라 콘솔에서 바꿀 것은 없음.
- **확인용 도구**(메뉴): 이용권 → "테스트: 결제한 것으로 보기", 설정 → "체험을 처음부터 다시".

## 아직 안 한 것 / 출시 전에 바꿀 것

1. **실제 서버 왕복 확인** — 만든 곳(Claude 작업 환경)에서는 Firebase에 못 닿아, 기록 올리기·불러오기는 실제 폰에서 확인이 필요.
2. 결제(스토어 계정 필요), 세력 변경권.
3. 판 수·이용권을 서버에 저장(지금은 기기에만 → 앱을 지우면 초기화).
4. 점수 저장을 정식 칸으로: 스토어 로그인 + `war/{달}` 집계 문서(GitHub Actions) — 바이블 5.2. 지금은 달마다 기록을 최대 500건씩 직접 읽음(3분 캐시).
5. 게임 안의 자체 세력 선택·순위 등록 화면과 허브 화면이 겹침 → 게임 쪽에 "허브에서 열렸을 때" 모드를 넣을지 결정.
6. 등급 기준 숫자는 임시값 — 실제 플레이 기록을 보고 조정.
7. 게임별 개인 순위판(본부에서 따로 논의하기로 함).
8. 앱 포장 — 뼈대는 `app/`에 준비됨(`app/앱_인계.md`). 실제 올리기·결제는 시뇽 명의 계정 생긴 뒤.
