# 앱 포장 인계

> 통합 앱 = 통합 홈(https://bluecfdc-spec.github.io/save-the-ocean/hub/)을 여는 껍데기.
> 게임·전장·점수를 고칠 때는 웹만 고치면 되고, 이 폴더는 다시 손대지 않는다.

## 지금 상태 (2026-11-25)

- 방식: Capacitor 7. 앱이 켜지면 통합 홈 주소를 바로 연다(`capacitor.config.json`의 `server.url`).
- 네이티브 폴더(`ios/`, `android/`)는 저장소에 두지 않는다. `node tools/prep.mjs ios|android`가 매번 새로 만들고, 아이콘·시작 화면·세로 고정·상태바 숨김을 넣는다.
- 자동 빌드: `.github/workflows/app-build.yml`
  - `app/`이 바뀌어 올라가면 → 안드로이드 시험판(APK) 만들기 + 아이폰 빌드 점검(서명 없이)
  - 수동 실행에서 `testflight` 선택 → 아이폰 서명 후 TestFlight 올리기
- 스토어 문구·스크린샷 초안: `스토어_자료.md`, `store/`

## 계정이 생기면 할 일 (시뇽 명의 Apple 개발자 계정)

1. App Store Connect에서 새 앱 등록, 번들 ID 정하기.
2. GitHub 저장소 설정에 넣기 (채팅으로 보내지 말 것)
   - 시크릿: `RUMBLE_ASC_KEY_P8`(.p8 내용), `RUMBLE_ASC_KEY_ID`, `RUMBLE_ASC_ISSUER_ID`, `RUMBLE_TEAM_ID`
   - 변수: `RUMBLE_BUNDLE_ID`
   - 오션 앱의 `ASC_KEY_P8`과는 다른 계정이라 이름을 따로 뒀다.
3. Actions → app-build → Run workflow → `testflight`.

## 확인된 것 / 안 된 것

- 확인: 작업 환경에서 `prep.mjs`가 안드로이드·아이폰 프로젝트를 만들고 설정을 넣는 것까지.
- 미확인: TestFlight 올리기 단계는 계정이 없어 한 번도 돌려 보지 못했다. 처음 돌릴 때 서명 설정에서 손볼 수 있다.

## 출시 전 남은 것

- 인앱 결제(전장 이용권) — 플러그인 추가 + `hub.js`의 테스트 버튼을 실제 결제로 교체.
- 통합 앱 이름의 개인정보 처리방침 페이지.
- 인터넷이 끊겼을 때 화면(지금은 빈 화면이 될 수 있음).
- 정식 아이콘, 실제 폰 스크린샷.
- 안드로이드 출시용 서명(지금은 시험판만).
